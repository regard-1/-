# 多特倍斯私域运营中台 MVP

这是面向一线运营人员的用户触达与回复执行中台。系统帮助运营人员查看本人负责的用户、理解当前沟通上下文、生成个性化话术并记录后续跟进。

## 当前范围

- 今日工作台：待回复、首次触达、约定跟进和即时会话队列；
- 用户资产：NMN、麦角硫因、辅酶 Q10、常规品四类用户列表；
- 内部 AI 辅助摘要：基于行为、产品关注和互动事实帮助运营理解用户；
- 会话工作台：录入客户最新消息，按场景生成、编辑、复制并记录回复；
- 触达任务：覆盖每日用户触达、意向逐层跟进、购买后定期关怀、生日关怀、中性公共事件关怀、沉默唤醒和客户回复；
- 每日优化：根据前一日开口率、回复率、意向率、转化率和各类触达内容，生成当天节奏与话术调整建议；
- 跨场景用户判断：结合已知事实与行为推断展示职业、年龄阶段、性格、生活节奏、决策方式、非产品话题、意向度和转化可能；
- 历史话术学习：导入 `金达威1V1触达(1).xlsx` 的触达、回复、意向、转化与删除口径，识别有效信号和打扰风险；
- 新客话术链路：破冰建联、标签采集、挖需、教育、对比、轻量促单、信息确认、支付跟进、物流通知、服用指导、效果追踪、复购增购和转介绍；
- 存量老客话术链路：沉睡唤醒、用户关怀、复购增购、定期维护和裂变转介；
- 活人感 Agent：承接真实上下文，一次只完成一个沟通目标，并给出不同语气备选及用户回复后的多轮接法；
- 合规与权限：展示角色可见范围、禁止操作和操作记录。

## 明确不包含

- 后台订单管理、发货、退款或财务逻辑；
- 经营分析、利润报表或管理层决策功能；
- 营销活动编排、预算配置或社群管理；
- 自动绕过运营人员确认向客户发送消息。

用户辅助摘要、内部标签、优先级和事实证据只在运营中台内部展示，生成的客户回复不得包含这些内部信息。

职业、性格、生活阶段等行为推断均显示置信度和依据，不得当作用户确定事实。公共事件关怀仅使用中性、公开且与所在地匹配的天气、交通、节假日等信息，不根据政治立场进行触达。

## 本地运行

```powershell
py -m http.server 8091
```

访问 <http://localhost:8091/>。也可以运行仓库中的 `server.py`，访问默认地址 <http://localhost:8090/>。
