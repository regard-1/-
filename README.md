# 多特倍斯私域运营中台 MVP

这是面向一线运营人员的用户触达与回复执行中台。系统帮助运营人员查看本人负责的用户、理解当前沟通上下文、生成个性化话术并记录后续跟进。

## 当前范围

- 今日工作台：待回复、首次触达、约定跟进和即时会话队列；
- 用户资产：NMN、麦角硫因、辅酶 Q10、常规品四类用户列表；
- 内部 AI 辅助摘要：基于行为、产品关注和互动事实帮助运营理解用户；
- 会话工作台：录入客户最新消息，按场景生成、编辑、复制并记录回复；
- 触达任务：管理具体用户的回复、跟进、约定时间及完成状态；
- 话术中心：首次触达、需求澄清、产品比较、异议、跟进和方案确认；
- 合规与权限：展示角色可见范围、禁止操作和操作记录。

## 明确不包含

- 后台订单管理、发货、退款或财务逻辑；
- 经营分析、利润报表或管理层决策功能；
- 营销活动编排、预算配置或社群管理；
- 自动绕过运营人员确认向客户发送消息。

用户辅助摘要、内部标签、优先级和事实证据只在运营中台内部展示，生成的客户回复不得包含这些内部信息。

## 本地运行

```powershell
python -m http.server 8091
```

访问 <http://localhost:8091/>。也可以运行仓库中的 `server.py`，访问默认地址 <http://localhost:8090/>。

## 主要文件

- `index.html`：GitHub Pages 入口；
- `templates/index.html`：Python 服务入口；
- `assets/app.js`：运营执行端交互；
- `assets/demo-api.js`：演示数据与静态接口；
- `assets/app.css`：运营中台界面样式；
- `tests/frontend_smoke.js`：触达工作流与数据边界测试。
